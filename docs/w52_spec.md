# 52주 신고가 매매 — 정의·점수 초안 (확인용)

후보 검토 우선순위를 보여주는 화면이다. **자동매매·주문 기능은 없다.** 점수는 매수 신호가 아니다.

## 1. 기준 정의

| 항목 | 정의 |
|---|---|
| 52주 최고가 (전일까지) | 기준일 포함 **달력 기준 1년(365일)** 의 **일봉 고가** 최댓값(한국투자증권의 52주 최고가와 같은 정의, 거래일로는 약 245일). 배치가 D일 저녁에 돌면 D일까지 포함해 D+1 장의 기준이 된다. 액면분할·병합·무상증자는 보정 |
| 신고가 이격률 | 현재가 ÷ 52주 최고가 − 1 |
| RS1M / RS3M | 시총 1000억 이상 전 종목의 21 / 63거래일 수익률 백분위(0~100, 동률은 중간 순위). 데이터가 모자란 종목 제외 |
| 5주선 / 20주선 | 주봉 종가의 5 / 20주 단순이동평균. 이번 주 미완성 봉 포함 |
| 5주선 우상향 | 5주선 오늘 값 > 1주 전 값 |
| BBW | 볼린저 밴드(20일, 2σ) 폭 ÷ 중심선. `bbw_pctile` 은 최근 120일 자기 이력 안의 백분위 |
| ATR14 / ADX14 | Wilder 방식. `atr_pct` = ATR14 ÷ 종가 |
| 평균 거래대금·거래량 | 최근 20거래일 평균(거래대금 0인 날 제외) |
| 업종 RS | 같은 KRX 업종 종목들 RS3M 의 중앙값(업종 4종목 이상). 업종 간 백분위로 환산 |

## 2. 실적 상태

최신 사업보고서(연간)·직전 연도·최신 반기(또는 분기)를 쓴다. 부채비율 200% 이상·적자·자본잠식·매출 2년 연속 감소는 기존 «실적 컷»과 같다(금융 업종은 부채·매출 컷 제외).

- **TURNAROUND**: 직전 연도 영업 또는 순이익 적자 → 최근 연간 흑자 또는 최신 반기 흑자, 그리고 부채비율 컷 통과
- **PASS**: 컷에 걸리지 않고 최근 연간 영업이익·순이익 모두 흑자, 최신 반기 OPM이 있으면 0 초과
- **FAIL**: 그 밖에 컷에 걸린 종목, **UNKNOWN**: 재무 자료 없음 (게이트 탈락)

## 3. 관리·위험 종목 제외

한국투자증권 현재가 응답의 플래그를 쓴다. 아래 중 하나라도 해당하면 제외한다.
관리종목(`mang_issu_cls_code`≠N) · 거래정지(`temp_stop_yn`=Y) · 투자경고·투자위험(`mrkt_warn_cls_code` 02·03) ·
단기과열(`short_over_yn`=Y) · 정리매매(`sltr_yn`=Y) · 종목상태코드 51·58·59.
**투자주의(01)는 제외하지 않고 표시만 한다.** 알 수 없는 코드는 제외하지 않는다.

## 4. 게이트 (모두 통과해야 후보)

시총 5000억 이상 · 평균 거래대금 50억 이상 · RS1M·RS3M 70 이상 · 5주선 우상향 · 현재가 > 20주선 ·
실적 PASS 또는 TURNAROUND · 관리·위험 아님.

## 5. 상태

| 상태 | 조건 |
|---|---|
| NORMAL | 이격률 < −10% |
| WATCH | −10% ≤ 이격률 < −5% |
| NEAR | −5% ≤ 이격률 < −1% |
| READY | −1% ≤ 이격률 < 0% |
| INTRADAY_BREAKOUT | 장중 현재가가 52주 최고가 초과 |
| CONFIRMED_BREAKOUT | 종가가 52주 최고가 초과 (종가 확정 이벤트) |
| FAILED_BREAKOUT | 장중 돌파 후 종가가 52주 최고가 이하 |
| EXTENDED | 돌파 기준가 대비 +10% 이상 |
| REBREAKOUT_WAIT | EXTENDED 이후 눌림 중이며 수렴: BBW ≤ 고점 시점의 0.7배, ATR% ≤ 0.8배, 5일 평균 거래량 ≤ 20일 평균의 0.7배 |
| REBREAKOUT | 수렴 구간(REBREAKOUT_WAIT 시작 이후) 고점을 현재가가 재돌파 |

돌파 이벤트(장중)와 종가 확정 이벤트는 분리한다. 상태는 종목별로 DB에 보존되어 날짜를 넘어 이어진다.

## 6. 점수 (정적 84점 + 장중 16점 = 100점)

| 항목 | 정적(배치) | 장중 가변 |
|---|---|---|
| RS 25 | 25 × (RS3M + RS1M) / 200 | — |
| 실적 25 | PASS 15 / TURNAROUND 12, ROE ≥20 +6 · ≥10 +4 · ≥5 +2, OPM ≥20 +4 · ≥10 +2 (상한 25) | — |
| 업종 20 | 12 × 업종 RS / 100 + 4 × (업종 내 신고가 −5% 이내 비율) | 업종 동반돌파 최대 4 |
| 돌파 품질 20 | 5 × (1 − bbw_pctile/100) + 3 × (1 − atr_pct 전 종목 백분위/100) | 상대 거래량 6, 돌파 캔들 품질 4, 돌파 폭 2 |
| 추세 10 | 5주선 우상향 3 · 20주선 위 3 · 5주선 > 20주선 2 · 240일선 위 2 | — |

장중 항목 기준
- 상대 거래량 = 누적 거래량 ÷ 같은 시각 기대 누적 거래량. 2배 이상 6점, 1.5배 이상 4점, 1.2배 이상 2점
- 돌파 캔들 품질: 현재가가 당일 고저폭 상단 25% 이내이고 시가 위면 4점, 상단 50% 이내이고 시가 위면 2점
- 돌파 폭: 52주 최고가 대비 0~3% 위면 2점 (너무 멀리 간 종목은 가점 없음)
- 업종 동반돌파: 같은 업종의 다른 종목이 돌파 중이면 최대 4점 (1종목 2점, 2종목 이상 4점)

## 7. 리스크 패널 (계산기)

계좌 2억원 · 거래당 리스크 1%(200만원) · 기본 손절 −8% → 포지션 = 200만원 ÷ 8% = **2,500만원**(최대 기본 포지션).
1/3 분할 진입(약 833만원씩) · +1R 도달 시 본절권 관리 · +3R 도달 시 50% 익절 · 잔량은 주봉 종가가 5주선 아래로 이탈하면 정리.
화면에 가격·수량 수준만 계산해 보여주며 **주문 기능은 없다.**
